# anime-shorts-assets

Хостинг изображений для проекта «Аниме-шортсы»: листы персонажей и утверждённые кадры.
Отсюда картинки подаются в модели генерации (Replicate, Hugging Face) по прямым ссылкам.

Рабочая папка проекта и все правила — на компьютере автора (`CLAUDE.md`, `00_docs/`).
Этот репозиторий — только склад картинок для моделей, не архив проекта.

## Структура

```
characters/<imya>/          — листы персонажей (канон): sheet_face.jpg, sheet_body.jpg, sheet_emotions.jpg
episodes/epNN_nazvanie/     — утверждённые кадры серии, которые нужно подать в модель
                              (правка, ракурс, проба движения, видеоклип): ep03_s02_k05_v1.jpg
lab/ГГГГ-ММ-ДД/             — картинки для экспериментов
```

## Ссылка для модели

```
https://raw.githubusercontent.com/tontio22/anime-shorts-assets/main/<путь к файлу>
```

## Правила

- Только наши собственные картинки. Никаких чужих персонажей, логотипов, фотографий людей.
- Репозиторий публичный: всё, что здесь лежит, видно всем. Лицензии нет — все права у автора.
- Кладём только то, что нужно подать в модель. Исходники и финалы живут в папке проекта.
- Формат — JPEG, качество 92, до ~1 МБ на файл. Имена — латиницей, как в проекте.
- Ничего не удаляем (история нужна, чтобы старые ссылки в заметках продолжали работать).
